# v1.0.0 —— 首次发布

一个**零依赖、零构建、浏览器内直接跑**的中国术数排盘内核。打开网页就排盘，不需要后端、不上传生日。

## 这个版本包含

- **15 个排盘引擎**（3,058 行）：八字 · 紫微斗数 · 大六壬 · 奇门遁甲 · 太乙神数 · 六爻纳甲 · 梅花易数 · 易经卦象 · 风水（玄空飞星 / 八宅）· 黄历择日 · 小六壬 · 象数 · 星命 · 现代占星 · 五行体质
- **历法内核**：1900–2100 公历/农历/节气/四柱，20 KB 静态表内嵌，离线可用
- **单页应用**：`index.html` 零构建，GitHub Pages 直接跑
- **命令行工具**：`npx xuanxue run bazi --y 1990 --mo 6 --d 15 --h 10`
- **可选 FastAPI 网关**：统一 `BirthInput` 请求模型 + 上游转发；缺上游依赖时返回 503 与安装指引，不崩栈
- **26 项冒烟断言**：`npm test` 验 15 引擎装载 / 核心排盘结构 / 历法覆盖

## 设计取舍

排盘由确定性算法算，**AI 只负责解读、不参与起局** —— 杜绝模型幻觉算出错的干支。
`kernel/ai/ai.js` 的 `apiKey` 默认为空，使用者自带 Key。

## 修掉的两个问题

- 性别下拉 `value="男"` 而引擎只认 `M/F`，导致命盘一律按女性算、大运顺逆颠倒
- `huangli(y,m,d)` 收到非法日期时崩在 `undefined.luck`，改为明确的 `RangeError`

## 已知边界

- 历法以「东八区 + 节气定月」为主口径；真太阳时按经度修正，但真太阳时 + 均时差的精细流派未全覆盖
- Python 侧 `/api/bazi` 等直算端点依赖**上游重型引擎**（kentaro2017 的 `kin*` 系列，MIT），本仓不打包
- 前端 15 体系开箱即用；更多重型星象体系请装上游客
